For this assignment, I created a program that plays morse code on the Arduino buzzer. When the makeshift alligator clip switch is open, the buzzer emits morse code for my name; when it is closed, it emits SOS morse code.

![arduino help photo](https://tashfaaa.github.io/assets/img/help.jpg)

{: .box-note}
**Tip:** It might be a good idea to start testing your code with a set of LEDs instead of the buzzer. Your ears would be grateful.
