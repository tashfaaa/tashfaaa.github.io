This assignment required us to create a program that plays music on our Arduino buzzer when a switch is turned on. My program plays the Pink Panther theme, and once the switch is turned off, it completes the ongoing loop and turns the buzzer off. The code I found for the theme used "#define" so I changed all instances of it to "const int." It also played the theme just once so I moved code around into the loop to change this.

![a photo of my board after i turn the switch/buzzer off](https://tashfaaa.github.io/assets/img/pinkpanther.jpg)

{: .box-note}
**Tip:** Complete the basic assignment before trying the extra credit stuff! I initially did the opposite (tried to incorporate the extra credit bit from the start) and ended up having to simplify my code later when I realized I couldn't figure it out. It makes a lot of sense to start with the normal version of the assignment and build on it afterward if you want to.
